# SketchUPbuildingTool 平面での作業ガイド

## 発行前に図面を確認する

1. 設計変更後は「図面・シーン → **モデルから全更新**」を押し、SKPを保存する。v1.31.0以前のシーンも、初回にこの手順で更新する。
2. 「発行対象」でセットを選び「LayOutへ配置」を押す。保存済みSKPでも、登録部材の属性・配置や階などが図面生成時と異なる場合は、発行対象の要更新図面を表示する。室一覧を出力・更新する場合は、面積の更新状態も確認する。
3. 平面に描いた断面の参照先がセットから外れている場合は、該当する図番が表示される。セットに断面を追加するか、意図して外す場合は「発行対象外の断面への参照を許可する」をオンにして発行する。
4. PDFが必要なら、出力したLayOutを開き、「ファイル → エクスポート」からPDFを選ぶ。[SketchUp公式の手順](https://help.sketchup.com/en/create-pdf)

更新判定は登録部材の属性と配置、階、単位、ルートのジオメトリなどを比較する。登録部材のグループ内を直接加工した場合やタグの表示だけを変えた場合も、発行前に全更新する。

## 柱芯から外壁を偏芯させる

1. 建築パレットの「壁」で、「基準線からの配置」を**「外・内寸法」**にする。
2. 「芯から外面」と「芯から内面」を入力する。例えば外面95 mm・内面55 mmなら壁厚150 mmになる。複合壁は層厚の合計を使うため、外面の寸法を入力すると内面が決まる。
3. 柱芯や通り芯をクリックして作図する。外周を閉じるときは最後に始点をクリックする。「外側の向き」が自動なら、閉じた経路は外周側、開いた経路は進行方向の右が外側になる。開いた壁では必要に応じて左・右を明示する。
4. 既存壁は選択して「寸法を編集」から設定を変える。図面は「図面・シーン → モデルから全更新」で更新する。

寸法はそれぞれ外側・内側への距離を正とする。例として外面140 mm・内面−20 mmなら、壁の両面が柱芯より外側に来る。壁厚が1 mm以上になるように入力する。複合壁の層順は、作図方向を向いて左から右。窓の外側が自動の場合、壁で指定した外側を使う。

Archicadの複合壁は、壁全体と躯体の外面・中心・内面から基準線を選べる。外面・内面を基準にオフセットも指定できる。[Graphisoft公式 Wall Tool Settings](https://help.graphisoft.com/AC/29/INT/_AC29_Help/150_UserInterfaceToolSettings/150_UserInterfaceToolSettings-3.htm)

Revitも、仕上げ面・躯体面・壁芯・躯体芯から位置基準を選び、作図時にオフセットを入力できる。[Autodesk公式 About the Wall Location Line](https://help.autodesk.com/cloudhelp/2018/ENU/Revit-Model/files/GUID-F26DB6DA-A0EC-424D-B656-3BDF47607F4F.htm) · [Autodesk公式 Place a Structural Wall](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-StructEng/files/GUID-B2F0D0D0-1C47-4514-97CB-80A57B377D4F.htm)

## 発行する図面をセットで保存する

1. 「図面・シーン」の**「発行セットを登録・編集」**を開く。セット名を入れ、発行する図面を選ぶ。建具表・室一覧の有無と、LayOutで単独配置か複数配置かも指定する。
2. **「セットを保存」**を押してSKPを保存する。「発行対象」でセットを選び、**「LayOutへ配置（A3横）」**を押すと、セットの図面と表を1つのLayOutに出力する。「全図面」を選ぶと登録済み図面を一式出力できる。
3. 次の発行でも同じセットを選べる。内容を変える場合は、対象を選んで編集し、セットとSKPを保存し直す。

図面の図番と登録済み縮尺は引き継ぐ。平面の断面参照先も同じLayOutに載せる場合は、その断面をセットに含める。追加する建具表・室一覧はモデル全体を集計する。削除した図面がセットに残っている場合は、発行前に選び直して保存する。

## 複数の図面をLayOutの1枚に並べる

1. 「図面・シーン」で各図面の縮尺を設定し、SKPを保存する。
2. 「LayOutの配置」で**「同じ種類の図面をまとめる」**を選び、「LayOutへ配置（A3横）」を押す。一般平面・梁伏図・断面は最大2図、立面は最大4図を1枚に配置する。
3. まとめた用紙にはM-01などのシート番号が付き、各図の見出しには既存のA-01などの図番と縮尺が入る。平面の断面記号にあるA番号は、断面の見出しと照合する。

同じ種類・縮尺で、余白と見出しを含めて用紙に入る図面をまとめる。収まらない図面は指定縮尺のまま単独のページに出す。建具表・室一覧は引き続き別シートに出る。

## 平面で断面位置を指定する

1. 一般平面シーンを開く。SketchUp標準の上面・平行投影ビューからも指定できる。
2. 「図面・シーン → 種類 → 断面」を開く。既存断面の位置を変更する場合は、先に「編集する断面」で対象を選ぶ。
3. **「平面で断面位置を指定」**を押し、モデル上で断面線の始点と終点をクリックする。線はX・Yのどちらかにそろう。右矢印でX、左矢印でYに固定できる。
4. 矢印のプレビューを見ながら、**断面に残して見る側**をクリックする。Escで一つ前の操作に戻る。
5. 設定欄に入った位置と向きを確認し、断面名を付けて**「作成・更新して開く」**を押す。始点と終点は切断位置と軸を決めるために使い、断面はその線を延長してモデルを切る。

一般平面の断面記号とLayOutへの配置は、標準の断面平面を取り込んだ場合と同じ。

## SketchUp標準の断面を図面にする

標準の断面平面を置くとSketchUp上でモデルが切れます。SketchUPbuildingToolの図面一覧、平面の断面記号、LayOutに載せるには、その断面を「図面・シーン」で登録します。

1. **3Dの作業ビュー**でグループやコンポーネントの編集を抜け、モデル全体に標準の断面平面を置く。世界X軸かY軸に正対する縦断面を使う。
2. 取り込みたい断面平面を**1枚選択**する。「図面・シーン → 種類 → 断面」を開く。登録済みの断面を直す場合は、先に「編集する断面」で対象を選ぶ。
3. **「現在のSketchUp断面を使う」**を押す。読み取った「見る方向」と「切断位置」を確認し、A-Aなどの断面名を付けて**「作成・更新して開く」**を押す。断面平面が手元になければ、方向と世界座標（mm）を直接入力しても作成できる。
4. モデルを横切る登録済みの断面は、一般平面に二点鎖線・矢印・断面名・図番が入る。SKPを保存して「LayOutへ配置」で断面シートも出す。すでにLayOutへ配置した断面は、同じ断面シーンを更新してSKPを保存し、LayOutで参照を更新する。新規断面はLayOutへの配置が必要。

**反映されないとき**は、断面平面がグループ内にないか、斜めや水平の断面を選んでいないかを確認する。標準の断面平面を動かした場合は、手順2から読み込み直す。「モデルから全更新」は、図面に登録済みの位置で描き直す操作。

切断位置が通り芯と重なる場合、一般平面では断面位置線を優先し、通り芯番号と寸法を残す。

## LayOutに建具表と室一覧を付ける

1. 平面の窓・扉に建具記号を入れ、対象の階に室名を登録する。「図面・シーン → モデルから全更新」を実行してSKPを保存する。
2. 「図面・シーン」で「建具表を付ける」「室一覧を付ける」から必要な表を選び、「LayOutへ配置」を押す。図面の後ろにT-01 建具表とT-02 室一覧を追加する。行数が多い場合は、見出し付きの続きページに分ける。
3. 建具表は、階・記号・形式・寸法・仕様の一致する窓や扉を数量でまとめる。記号の未入力と、同じ記号で仕様が異なる箇所を表で確認する。室一覧では、境界が未確定の室を備考に出し、面積の合計から除外する。

### 既存LayOutの表を更新する

1. SketchUpで元のSKPを開き、「図面・シーン → モデルから全更新」を実行して保存する。LayOutで追記した場合も、先にLayOutを保存する。
2. 「図面・シーン → **既存LayOutの表を更新**」を押し、建具表・室一覧を配置済みのLayOutを選ぶ。元と同じフォルダに別名で保存する。
3. コピーには表本体と集計欄の更新が入り、既存ページ、図面の配置、表の外に書き足した注記を維持する。表のセルに直接入力した内容は、モデルの内容で置き換わる。

行が増えたときは続きページを追加する。行が減ったときは既存ページに「続きなし」と表示し、そのページに書き足した注記を残す。図面のビューポートは、コピーをLayOutで開いてSKPの参照を更新する。

表の更新にはLayOut 2026以降が必要。v1.26〜1.27のLayOutは、元のページ名・図番見出し・列見出し・集計欄から対象を識別する。旧版のファイルを選ぶときは、開いているSKPがそのLayOutの参照元と同じか確認する。

## 一般平面と梁伏図を別々に出す

1. 「図面・シーン」で「梁伏図」を選び、梁が支える床の階を指定する。2階床下の梁なら「2FL」を選ぶ。
2. 梁の天端が2FLと同じならオフセットは0 mm。例えば天端が床面より180 mm下なら−180 mmを指定する。拾う範囲は指定した高さを中心に既定で±150 mm。
3. 「作成・更新して開く」を押す。梁の輪郭、梁下の高さで切った柱、通り芯と寸法を表示する。「梁の断面寸法・鋼材規格を表示」は必要に応じて切り替える。
4. SKPを保存し、「LayOutへ配置」で一般平面・立面・断面と一緒に出す。すでに梁伏図を配置済みのLayOutには、モデルから全更新してSKPを保存した後、参照更新で変更を反映する。初めて梁伏図を追加する場合はLayOutへの配置が必要。

同じ階の一般平面と梁伏図は、シーン・図番・縮尺を個別に保存する。梁伏図では建築パレットの梁を対象とし、階段・建具・室・床仕上げの表示を省く。

## 設計変更を既存のLayOutへ反映する

1. SketchUpでモデルを変更した後、「図面・シーン → モデルから全更新」を実行する。平面の室面積、立面の屋根高さ、断面の階高などを確認する。
2. SKPを同じ場所・同じ名前で保存する。
3. 既存のLayOutを開き、「ドキュメント設定 → 参照」でSKPを選んで「更新」する。図番・縮尺・ビューポート配置とLayOut上の注記を確認して保存する。

## 室名・室面積と階高を表示する

1. 対象階の平面を開き、建築パレットの「室」を押して、閉じた壁の内側をクリックする。室名を入力すると、その点に室名と室面積が出る。同じ室内をもう一度クリックすると名前と表示位置を変えられる。
2. 面積は建築ツールの壁の内法で計算し、室に重なる床開口を控除する。孤立した柱型や家具は控除しない。建具の開口は室境界を分断しない。
3. 壁を動かしたら「図面・シーン → モデルから全更新」。室の面積と、階別一覧・CSVの「室面積_m2」が更新される。境界が開くか複数の室が同じ範囲に入った場合は「室境界を確認」と出る。
4. 「図面・シーン → 断面 → 階高寸法を表示」で上下レベル間の実寸を出す。既定は表示で、GLは階高の計算から外す。

## 床開口と直階段を作る

1. 上階の床スラブを選び、建築パレットの「床開口」を押す。開口の対角を2点クリックすると、床の全層に矩形の穴が開く。
2. 床を選んだまま「直階段」を押す。床開口、下階レベル、上る方向、蹴上げの段数を指定する。向きは床のローカルX・Y軸に沿う。
3. 「図面・シーン → モデルから全更新」で、下階平面に上り矢印・切断記号・上方の破線、上階平面に開口、縦断面に段形状を表示する。階別一覧とCSVの「床面積_m2」には開口を引いた面積が出る。
4. 床を右クリックして「床開口を編集」を選ぶと、位置・寸法を変更できる。階段は開口に追従する。床を階に関連付けると、上階の階高変更に床と階段が追従する。向きや段数は3Dで階段を右クリックして編集する。

階段に使っている開口を消す場合は先に階段を削除する。対応する階段は直階段。段寸法はモデル値として表示する。

## 屋根を配置する

1. 建築パレットの「屋根」を押し、片流れか切妻を選ぶ。勾配方向、勾配、軒の出、鉛直方向の厚さを指定する。
2. 作図レベルを選び、そのレベルから低い軒の上端までの高さを入力する。切妻の棟は勾配方向と直交する。
3. 平面で外壁矩形の対角を2点クリックする。配置後は屋根を選び、パレットの「寸法を編集」で設定を直せる。
4. 「図面・シーン → モデルから全更新」を実行する。屋根が1件で立面の軒高・棟高が両方空欄の場合、屋根から自動で高さを表示する。片流れは高い側を「屋根最高」と表示する。

屋根を登録済みの階から作ると階高変更に追従する。屋根のIFC書き出しは今後の工程とする。

### 壁を屋根の下面に合わせる

1. 壁を選び、建築パレットの「壁上端の納まり」で「屋根下面に合わせる」を選ぶ。
2. 一覧から参照する屋根を選ぶ。壁厚全体を覆う屋根を1件指定する。切妻の棟をまたぐ場合は壁上端を2面に合わせる。
3. パレットで屋根の勾配や厚さを変更すると、関連付けた壁が追従する。SketchUp標準の移動ツールで屋根を移動したときは、「図面・シーン → モデルから全更新」で壁と図面を更新する。
4. 「固定高さ」を選ぶと、屋根への関連付けを外し、関連付け前の高さに戻す。

壁上端が既存の窓・扉に掛かる場合は、開口か屋根の位置を見直す。

## 1. 通り芯を置いて作業する階を開く

1. 建築パレットの「通り芯」を押し、間隔を設定してモデル上の原点をクリックする。
2. 登録済みの階の平面と、＋X・−X・＋Y・−Yの立面がシーンタブに追加される。初期設定は1FL・2FL。作業する階の「SBR｜平面」を開く。
3. 既存モデルで通り芯が黒い実線に見えるときは、建築パレットの「通り芯の表示・仮シーンを整える」を押す。作業ビューのエッジ色を材質色表示にして、登録済みの平面も更新する。作業中の他のエッジ色も現在のスタイルに応じて変わる。

通り芯の配置で自動作成したシーンは、図面一覧で「仮」と表示する。壁や柱を作図したら「図面・シーン → モデルから全更新」で図面化する。

平面図の通り芯番号は、寸法列の外側で通り芯の両端を丸で囲んで表示する。既存モデルでは「図面・シーン → モデルから全更新」を実行してSKPを保存し、LayOutの参照を更新する。

## 2. 平面を開いたまま窓・扉を入れる

1. 建築パレットかツールバーで「窓開口」または「扉開口」を押す。形式、幅・高さ、建具記号、配置基準点を選ぶ。窓は腰高と取付位置も設定する。
2. 平面で壁にカーソルを重ね、配置基準点をクリックする。中心・区間始点側の端・区間終点側の端から選べる。
3. 向きを持つ形式は、表示された記号を確認して2回目をクリックする。Escで位置選びに戻る。

| 形式 | 確定操作 |
| --- | --- |
| 片開き扉・親子開き | 2回目で主扉の吊り元と開く壁側を選ぶ。親子開きは子扉幅も入力する。 |
| 両開き扉 | 2回目で開く壁側を選ぶ。 |
| 片引き（壁付け） | 2回目で引く方向と、戸を取り付ける壁側を選ぶ。 |
| 引分け（壁付け） | 2回目で戸を取り付ける壁側を選ぶ。両側の引き代を確認する。 |
| 折れ戸 | 2回目で折りたたむ端と折れる壁側を選ぶ。 |
| 引違い（2枚）・開口のみ | 1回目で確定する。 |
| 片引き窓・片開き窓・縦すべり出し窓 | 2回目で可動側または吊り元側を選ぶ。 |
| 引違い窓・FIX・両開き窓・横すべり出し・上げ下げ・内倒し・外倒し | 1回目で確定する。 |

壁付けの片引き・引分けでは、引き代が同じ壁区間に収まり、ほかの開口と重ならないことを確かめる。扉の簡易形状は閉じた戸板を生成し、平面では形式別の記号を使う。

引違い・片引き窓は、平面で枠、二列の障子、召合せを表示する。立面と3Dにはガラスを囲む障子框が出る。扉には三方枠が付き、親子開きでは主扉と子扉の幅が分かる。「図面・シーン → モデルから全更新」で、図面記号と配置済みの簡易建具を更新する。開口だけを保存していた古い建具は「平面の建具を編集」で形式を設定し直す。

窓の取付位置は外壁面合わせ・インセット・アウトセットから選ぶ。インセットは外壁面から内へ、アウトセットは外へ指定距離だけ移動する。自動では閉じた壁芯経路から外側を判定し、開いた壁では区間始点から終点を見て右側を使う。左・右は手動でも指定できる。簡易サッシは閉じた状態の形状を作る。

登録済みの平面シーンでは、その階の壁と図面注記を同時に更新する。旧版の窓に残っている扉風の円弧は「モデルから全更新」で消える。旧版の形式未指定の窓は、製品がFIXの場合を除き引違いの平面記号を使う。既存窓で形式・取付位置を変更する場合は「平面の建具を編集」を使う。

「図面・シーン」でその平面の「記号付き建具の位置・幅寸法を表示」を有効にすると、記号付きの開口を寸法列に含める。腰高が切断高さより上の窓は、平面の切断高さを変えるか、3Dの壁面から配置する。

## 3. 既存の窓・扉を平面で直す

1. 建築パレットの「平面の建具を編集」を押し、変更する窓・扉の**開口部分**をクリックする。
2. 開いた編集欄で、壁区間の始点から開口中心までの距離、幅、高さ、開き勝手などを設定する。
3. 「変更を反映」を押す。ほかの平面・立面・断面も更新するときは「モデルから全更新」を使う。

鋼管柱と重なる壁は平面シーンで専用の投影を表示する。その壁の窓・扉も同じ「平面の建具を編集」で選ぶと、元の壁に変更が入る。壁本体を直接選択する場合は3Dの作業ビューを開く。

## 4. ツールバーと建築パレットを行き来する

作図レベル、手入力のZ、構造種別はモデルの作図条件として共有する。パレットで1FL（+450 mm）を選んだら、ツールバーの柱や壁も同じレベルで始まる。寸法・断面・通り芯間隔は作業中のモデルで保持し、どちらのボタンからも呼び出せる。柱と梁の寸法は木造・鉄骨・RCごとに覚える。連続作図の途中で設定を変えた場合は、次の要素から新しい設定を使う。

## 5. 布基礎を角までつなぐ

「布基礎」を押して、基礎芯の始点と各角を順にクリックする。L字などはEnterで確定し、外周を一周する場合は最後に始点をクリックする。同じ経路に含めた立上りと底盤は一体のソリッドになる。

## 6. 矢印キーで軸を固定する

- **右 → X（赤）／左 → Y（緑）**　壁・梁・床・基礎などは直前の点を通る軸に沿って次の点を置く。始点や柱・通り芯などの1点配置では、キーを押したときのカーソル位置を基準にする。
- **上 → Z（青）**　カーソルのXYを保持して高さを選ぶ。立体ビューで高さを確認してクリックする。壁・床・布基礎などは経路全体が同じ高さになる。登録レベルと異なる高さで置いた部材は、手入力の高さとして作図する。
- 窓・扉では、左右矢印でX・Y方向の壁に絞れる。上矢印は現在の開口位置を壁上に固定する。建具の高さは腰高・開口高さで設定する。
- 同じ矢印を押すかEscで解除する。

## 7. 作業背景を暗くする

建築パレットの「暗い作業背景」を押すと、SketchUpの作業ビューをチャコール色、線を明るい色に切り替える。同じボタンで元に戻る。図面用シーンには白地と濃い線色を設定する。LayOutへの自動配置ではビューポートの背景を非表示にするため、用紙の白が出る。手動で配置した既存ビューポートも「SketchUpモデル → スタイル → 背景」をオフにできる。

新規のLayOut自動配置では、建具の細い線がつぶれにくいように、ビューポートの線幅を1:50で0.35 pt、1:100で0.25 ptに設定する。既存のLayOutを参照更新して使う場合は、そのビューポートで線幅を設定する。

## 8. 立面に方位名と高さを入れる

1. 「図面・シーン → 立面」を開く。「北の方向」で敷地の北がどの世界軸側か選ぶ。
2. 注記する立面の「見る方向」を選ぶ。「記号付き建具の上端・窓下端を表示」をオンにする。軒高・棟高はZを直接入力するか、モデルで水平辺を1本選び、「選択辺から軒高」または「選択辺から棟高」を押して読み取る。
3. 「作成・更新して開く」を押す。北の方向を変えた場合は、登録済みの立面名も更新する。既存シーンと図番を使う。

建具高さはモデル座標のZで示す。手前の建築ツールの壁に隠れた開口は省く。同じ高さ・同じ種類の注記は「ほか○件」にまとめる。既存LayOutの見出しやシート名を編集して使っている場合は、方位変更後に見出しやシート名も合わせる。

屋根を変更したときは、軒高・棟高をもう一度読み取って更新する。

## 9. A3の図枠に案件欄を入れる

「図面・シーン」の「図枠の案件情報」を開き、案件名・案件番号・作成者・発行日を入力して「LayOutへ配置（A3横）」を押す。案件名を空欄にするとモデル名が入る。図番、図面名、縮尺は各シートの設定から入る。

LayOutでは「図枠・案件欄」共有レイヤーにある案件情報を1箇所で修正できる。図面ごとの見出しと縮尺は個別に編集できる。
