# LayOutで平面・立面・断面を成立させる

## 完成条件

同じSKPから出した平面・立面・断面をA3横のLayOutにまとめ、印刷原寸で縮尺が合い、第三者が位置・向き・高さ・切断箇所を読み取れること。設計変更後は、図面シーンを更新してSKPを保存し、既存のLayOutで参照を更新して図面の配置を保てること。

| 図面 | 受入時に見るもの | 実装した処理 | 次に補う点 |
| --- | --- | --- | --- |
| 階別平面 | 壁・床・開口・柱の位置、通り芯とスパン、建物全体の寸法、断面を切った位置と見る向き | 赤の一点鎖線、外形全長、断面名・図番と矢印、柱の実断面、扉の開き勝手を表示する。記号付き建具の位置・幅寸法と壁・床の層別ハッチは図面ごとに選べる。 | 部屋名、実方位、床面より下の要素や上方にある部材の投影ルール。 |
| 立面 | どの方向から見た図か、外形と開口、GLと各階の基準高さ | 方位名を付け、GL・階レベル・建具上端と窓下端・軒高・棟高を表示する。近いラベルは目盛から引き出して間隔を確保する。 | 屋根・軒などのモデル形状の作図。 |
| 断面 | 平面の断面記号との一致、切断した壁・床・梁と背景の見分け、上下の高さ | 断面名と図番を平面と共用する。GLと階レベル、太い切断線、壁・床・梁・柱・基礎のハッチ、選んだ梁の梁下寸法を表示する。見通しの奥行きを指定できる。 | 階高・天井高などの寸法。 |
| LayOut | A3、図番、図面名、原寸印刷時の縮尺、既存図面の参照更新 | 平面・立面・断面を1ページずつ配置し、共通図枠・案件欄、図番、縮尺、単位を入れる。既存LayOutの参照更新は木造とRC造で確認した。 | 1シートに複数ビューを配置する。 |

部屋名、仕上表、詳細図、複数図面の1枚への配置は、3種類の図面が通った後に追加する。構造計算と構造的な納まり判定は別工程とする。

## ハッチと柱の表示方針

実際に切った領域からハッチを作る方法は維持する。一般平面では柱の輪郭、開口、寸法、通り芯が先に読めるように、壁・床の層別ハッチは初期状態で省く。詳しく見せる平面では「平面に壁・床の層別ハッチを表示」を選ぶ。断面では切断した壁と床の層別ハッチを残し、輪郭より淡いグレーで描く。

柱はモデルの実断面を描き、柱と重なる壁線・壁ハッチを切り欠く。角形鋼管は外周と中空部を分ける。これは図面の線の整理であり、部材の接合や数量計算のルールとは別に扱う。

壁・床の層別ハッチの間隔は紙面上で1.7 mmとする。紙面上の層厚が0.35 mm未満なら、層の輪郭を残してハッチを省く。図面を作るときに縮尺をシーンへ保存し、LayOutでも同じ縮尺を使う。縮尺を変えるときは「図面・シーン」で縮尺を選び、「モデルから全更新」してSKPを保存する。

## 確認する順番

1. 木造2階建てで平面2・立面4・断面2を作る。平面で赤い一点鎖線、黒い寸法線、外形全長、断面名と矢印を確認する。
2. 立面と断面でGL・1FL・2FLのラベルと切断面を確認する。断面が指定した位置と向きで切れていることを平面側と照合する。
3. A3のLayOutを出力し、図番・表記・実縮尺を照合する。例えば1:50の図面で、7,280 mmの間隔は用紙上で145.6 mmになる。
4. 窓・通り芯・断面位置のどれかを変更し、既存のLayOutで参照を更新する。配置と縮尺を保ったまま形状・注記が更新されれば、図面機能の最低限を満たす。

## v1.4.0プレビューの実機結果

木造2階建てで平面各階9本の柱を描いた。壁・床の層別ハッチを切り替えても柱断面数は同じ。木造・RC・鉄骨の実形状を別途切り、角形鋼管の外周と中空部を確認した。木柱の奇数断面寸法の端数を保持するよう作図処理を修正した。旧版の柱を図面化する際は現在の実形状を読むため、旧版の柱を規格寸法へ直すには部材を再生成する。

## v1.5.0プレビューの実機結果

同じ木造2階建てで既存の8シーンを作り直し、シーンのIDを保ったまま1:50と1:100のLayOutを作成した。両縮尺で全8ページのビューポートの実縮尺を照合した。断面A-AとB-BのPDFでは壁・床の層別ハッチ間隔が両縮尺とも1.7 mmで、切断線は1.5 ptだった。A-Aの背景線は0.5 pt。GLと1FLの実高さの差が450 mmの箇所では、1:100の文字の間隔を紙面上で6.5 mmとし、目盛は実高さに置いた。

既存LayOutの参照更新は、梁表示を追加したv1.6.0で通し検証した。

## v1.6.0プレビューの梁表示

一般平面では、切断面より上の梁と、天端が床面以下の梁を省く。切断面に掛かる梁と、床面から切断面までの範囲に見える梁はモデルの表示に従う。見上げの梁伏図は別の表示設定として扱う。Archicadも梁の切断部・見上げ部・投影部を区別する。 [Archicadの梁表示設定](https://help.graphisoft.com/START/25/INT/_AC25_Help/040_ElementsVB/040_ElementsVB-53.htm)

縦断面は梁の実形状から輪郭と斜線を作る。壁・床の層と重なる領域では梁の斜線を省く。断面の奥に見える梁は通常の投影線で表示する。木造・RC・鉄骨は同じ斜線を使い、断面形状で見分ける。

### 既存LayOutの参照更新

木造2階建ての窓幅・通り芯間隔・梁成を変更し、図面シーンを再生成して同じSKPに保存した。LayOutの「ドキュメント設定 → 参照 → 更新」を実行したファイルを再読込し、更新済みSKPが取り込まれ、全8枚のページ名・参照シーン・ビューポート枠・1:50の縮尺が維持されたことを照合した。PDFでは1階平面の窓幅1,950 mmと通り芯間隔3,800 mm、断面A-Aの梁下端の120 mmの移動と斜線の更新を確認した。

## v1.7.0プレビューの断面参照

平面の断面矢印に「A-A / A-07」のように断面名と図番を表示する。図番はSKPの各図面シーンに保存し、LayOutの見出しにも同じ値を使う。既存モデルでは「モデルから全更新」で現在の図面シーン順に最初の図番を割り当てる。以降は並べ替えても図番を保持し、追加した図面には次の番号を付ける。

改名は「図面・シーン → 断面 → 編集する断面」で対象を指定する。改名した断面を既存のLayOutで使う場合は、参照を更新し、シート名と見出しに入力済みの断面名をLayOut側で編集する。新規出力には変更後の断面名が入る。

木造2階建ての全8図面で、平面の「A-A / A-07」「B-B / A-08」とLayOutの見出しを照合した。B-Bを前に移し、A-AをA1-A1に改名してから、A-Aを別の断面として追加した。A-08とA-07は維持され、新しいA-AにはA-09が付き、平面2枚の参照と一致した。

## v1.8.0プレビューの梁下寸法と切断面

SketchUp上で梁を1本選び、「図面・シーン → 断面 → 梁下寸法」で「選択中の梁を使う」と基準レベルを指定する。切断面と梁の実形状が交わる位置で、基準レベルから梁下端までの高さを表示する。登録した梁・基準レベルは断面シーンに保存される。「モデルから全更新」で形状を測り直し、参照先を失った場合は寸法を省いて通知する。

梁の斜線に対し、柱は逆向きの斜線、布基礎・独立基礎は水平線で描き分ける。ハッチは切った領域に描き、壁・床の層との重なりを除く。断面の奥に見える部材は通常の投影線で表示する。

木造2階建ての断面A-Aで、1FLから梁下端までの2,410 mmを1:50と1:100で照合した。梁成を360から240 mmに変更すると、梁下寸法は2,530 mmへ更新された。断面B-Bでは梁・柱・基礎の切断ハッチを確認した。

## v1.9.0プレビューの見通し範囲

「図面・シーン → 断面 → 見通しの奥行き」に、切断面から表示する距離をmmで入力する。空欄は制限なし。建築部材やグループ内の面・線も、境界をまたぐ場合は範囲内だけを図面用に描く。モデル部材の編集には元の形状を使う。図面用形状は「モデルから全更新」で作り直す。

木造2階建てのA-Aで1,200 mm指定と制限なしを1:50・1:100で照合した。図番、手前のハッチ、梁下2,410 mmを保持し、奥の部材の投影を省いた。画像やグループ内の独自の断面設定は、境界をまたぐ図面用形状への再現対象外。

## v1.10.0プレビューの建具表示

建築パレットで扉を配置するとき、または親壁を編集するときに、区間始点側・終点側の吊り元と、壁芯の左・右の開く向きを選ぶ。配置時に軌跡をプレビューし、平面の切断高さに掛かる扉を扉線と90度の円弧で表す。既存の扉には開き勝手を設定するまで従来の開口記号を使う。開き勝手は平面の記号として扱う。

「図面・シーン → 記号付き建具の位置・幅寸法を表示」を有効にすると、切断高さに掛かる記号付き建具について、壁区間の始点から各開口の端を結んだ寸法列を表示する。寸法の単位はmm。壁の開口を編集して「モデルから全更新」を実行すると、扉線、円弧、記号、位置・幅寸法を更新する。

木造2階建てで1階2箇所、2階1箇所の開き勝手を設定した。窓W-01Rを編集した後、建具寸法列で開口端までの1,050 mm、開口幅2,100 mmと、次の開口までの距離が更新されることを1:50・1:100で照合した。
