# SketchBRep 建築ツール 開発ロードマップ

2026年11月9日現在 · v1.0.0

## 実装する順番

1. **作図の入口を揃える — 完了（v0.3.0）**
   - 階・木造／鉄骨造／RC造・部材・寸法を建築パレットで選ぶ。
   - 壁、床、柱、梁、通り芯、布基礎、独立基礎を作図し、選んだ要素を数値で編集する。
   - 完了条件は、作図後も部材の種類と寸法がSKPに残り、選択した要素を編集できること。鉄骨は既存の鋼材ジェネレーター、木造はSketchBRepの断面表を使う。

2. **部材を関連付け、モデルから一覧を出す — 完了（v0.4.0）**
   - 柱脚・中間・柱頭に芯点を持たせ、梁などの作図時に吸着する。既存の対応柱にも右クリックから芯点を付けられる。
   - 窓・扉開口は親壁に保存し、寸法・位置・記号を壁から編集する。
   - 階・種別で要素を絞り、開口の行から親壁へ移動できる一覧とCSVを作る。
   - 完了条件は、角形鋼管の中空でも芯が拾え、壁厚変更後も開口が残り、開口控除後の壁体積と建具記号を一覧から取得できること。

3. **開口に建具を入れ、部材をつなぐ — 完了（v0.5.0）**
   - 親壁の窓開口に、インストール済みのLIXILサッシジェネレーターから製品を選ぶ。開口の位置・寸法を編集すると、壁穴とサッシが一緒に更新される。建具一覧は「モデルから更新」で製品IDと変更寸法を読み直す。
   - 明示的に関連付けた柱・梁・壁が、通り芯の間隔・原点と階の高さの数値編集に追従する。既存部材も各芯点を交点から10 mm以内に置けば関連付けできる。
   - 完了条件は、窓のサイズ変更と通り芯の原点移動で対象の形状と建具一覧が更新され、各変更を一回のUndoで戻せること。
   - 追従の操作入口はパレットからの数値編集。サッシの生成・寸法変更にはLIXILサッシジェネレーターが必要。参照中の通り名を消したり変えたりする場合は、先に関連付けを解除する。

4. **平面・立面・断面をモデルから出す — 完了（v1.0.0で通し検証）**
   - 完了。階別平面、世界軸4方向の立面、位置と見る側を指定した断面をSketchUpのシーンに保存する。
   - 完了。平面に壁の切断線、切断高さにかかる窓・扉の記号、通り芯とスパン寸法を生成する。開口を変更したら「モデルから全更新」で同じシーンに反映できる。既存の作業シーンと図面用スタイルは分けて管理する。
   - 完了。壁は左から右、床は天端から下の順に層を指定する。各層はソリッドとして作り、平面・断面のハッチと開口控除後の層別体積を同じ形状から求める。
   - 完了。「図面・シーン」から登録シーンをA3横のLayOutファイルに1シーン1ページで配置する。実機で4ページの作成と再読込、参照先SKPのパスと各ビューポートのシーンを確認した。
   - 完了。SKPの図面シーンを更新・保存し、既存のLayOutを「ドキュメント設定 → 参照 → 更新」で更新した。1階平面に変更後の窓記号と通り芯寸法が反映された。全8ページでページ名、配置枠、参照シーンが一致した。
   - 完了条件は、モデルを直したあと、平面・立面・断面と建具表を手で描き直さず更新でき、作成済みのLayOutにも変更が反映されること。

5. **IFCで受け渡し、実案件に近いモデルで通す — 完了（v1.0.0で通し検証）**
   - 「図面・シーン」の「IFC4を書き出す」から、階・壁・床・柱・梁・土台・基礎・開口・配置済みサッシを出力する。部材の主要寸法、開口控除後の体積、壁と床の層別体積も渡す。書き出しにはSketchUp 2026以降と保存済みのSKPが必要。
   - SketchUp 2027をMCP経由で操作し、木造・鉄骨・RCの部材を含む検証モデルを書き出した。IfcOpenShellで階の高さ、部材分類、壁と開口とサッシの関係、形状と数量を照合した。同じ保存先のSKPから再出力した場合の部材IDの一致も確認した。
   - 木造2階建ての検証モデルで、窓幅を1,650から1,800 mmに広げ、通り芯を300 mm動かした。関連付けた柱・梁・間仕切壁、図面8シーン、建具・数量一覧、IFC4を更新した。1階外周壁の体積は9.30030から9.27555 m³に変わった。
   - IfcOpenShellで建築部材47件、開口7件、サッシ4件の形状を読み込み、変更前後で全58件のIDが一致することを確認した。IFC4のスキーマとEXPRESS規則の検証はエラー0件。IFC Navigatorで階別表示、開口とサッシの形状、窓幅・製品ID、壁の属性を目視確認した。
   - 完了条件は、SketchUpで作図・変更・再出力したあと、別のIFCビューアでも階・種類・親子関係・数量が追えること。

## v1.0の完成ライン

**ひとつのSKPから、修正に追従する図面・建具表・数量・IFCを出せること。** 木造2階建てを、通り芯と階の設定から、作図・建具配置・設計変更・図面更新・IFC確認まで一周通して判定する。鉄骨・RCの柱梁と基礎も実形状・属性・数量を検証する。

Archeformに近づいたかは、機能の数よりもこの一連の作業で判定する。屋根・階段・設備の専用ツールや、構造計算は別の開発段階として扱う。v1.0の木造2階建ては検証用に作成したモデルで、扉は開口として扱った。

## v1.0以降に進める順番

1. **床を階に追従させる — v1.1.0プレビュー**
   - 建築パレットで床を選び「階に関連付け」で階を指定する。階高編集時に関連付けた床が壁・柱・梁と一緒に動く。
   - 実機で2FLを2,940から3,150 mmに変更し、関連付けた床・壁・梁の移動、1階床の位置と2階床の数量の維持、ロック時の変更取り消し、2階図面の切断高さ更新を確認した。
   - 保存後の再読み込みと、階高変更後のIFCの照合が残る。
2. **2階床まわりの壁上端を納める — v1.2.0プレビュー**
   - 建築パレットで壁を選び「壁上端の納まり」から「床下面で止める」「梁下で止める」「外壁を上階につなぐ」を選ぶ。外壁をつなぐ場合は、壁を2層以上に分け、外装側の端の1層と上階の外壁を指定する。
   - 階高や参照部材の寸法編集に合わせて再計算する。SketchUpの移動ツールで直接動かした場合は「壁上端の納まりを更新」、または「図面・シーン → モデルから全更新」を使う。
   - 外装面が上階の外壁とそろわない場合や、延長する外装層が指定した床・梁と重なる場合はメッセージを表示する。部材同士を自動で切り欠く交差処理は次の段階。
   - 寸法計算、開口と外装層の切断線、参照変更時の追従をテストした。SketchUpでの立体再生成・保存・IFCの通し検証が残る。
3. **扉を建具として扱う — 次段**
   - 枠・扉本体・開き勝手を開口に関連付け、建具表とIFCへ出す。
4. **構造材を表示で見分けられるようにする — 後段**
   - 木造の柱・梁と木土台は木目、布基礎・独立基礎とRC部材はコンクリート、鉄骨は濃いグレーを標準にする。
